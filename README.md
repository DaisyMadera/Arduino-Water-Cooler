# Arduino Water Cooler

An Arduino water cooler prototype created for a CPE 301 final project. The project uses temperature readings and control logic to operate the system’s components.

## Project files

- [Arduino source code](Final_Code.ino)
- [Technical document (PDF)](Technical%20Document%20-%20Final%20Project%20CPE%20301.pdf)

## Software

Use the **Arduino IDE** to open, compile, and upload the Arduino code.

## Running the code

1. Connect the Arduino board to your computer with a USB cable.
2. Open `Final_Code.ino` in the Arduino IDE.
3. Select the matching board and port from the **Tools** menu.
4. Click **Verify** to compile the code.
5. Click **Upload** to send the code to the board.

See the technical document for details about the project design and components.
